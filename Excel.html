Learn Microsoft Excel 2016

Microsoft Excel is a spreadsheet application developed by Microsoft. It’s part of the Microsoft Office suite and is used to organize, analyze, and visualize data. Learn the basic tools and steps to master Excel 2016 below.

Step 1: Open Microsoft Excel 2016 and select a blank workbook

Start Excel and choose “Blank Workbook” to begin your spreadsheet project.

Step 2: Create and format spreadsheets

Use cells to enter data, apply formulas, and style your sheet for better readability.

Step 3: Adjust page layout using the Layout tab

Modify margins, orientation, and paper size for printing and better presentation.

Step 4: Use formulas and functions

In the “Formulas” tab, use built-in functions to automate calculations easily.

Step 5: Import data from external sources

Use the “Data” tab to import data from Access, the web, or text files.
